# hxwl-12 未成年人个案授权与保密台账

在「心理咨询个案记录」原型上扩展的授权与保密台账：会谈记录只有在有效监护人授权范围内才进入正式档案。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 业务规则

- **授权台账**：每个未成年个案登记监护人（姓名/关系/电话）、可谈范围、有效期限，支持登记与续签。
- **会谈入档**：提交会谈记录时自动校验——会谈日期在授权有效期内且主题在可谈范围内 → 进入正式档案；否则存为**受限草稿**并记录拦截原因，不进入正式档案。
- **紧急临时提交**：督导写明紧急原因与回访期限后，受限草稿可临时提交（provisional）；回访逾期会高亮提醒。
- **补签 / 关闭**：临时提交的记录由监护人补签后转入正式档案，或经督导评估关闭封存；每次状态变化都追加版本，**版本链完整保留**。
- **变更记录**：授权登记/续签、入档、拦截、临时提交、补签、关闭全部写入台账。

## 模块划分（授权、会谈、变更记录、本地保存分开实现）

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 领域类型（授权、个案、会谈记录、版本、台账） |
| `src/domain/authorization.ts` | 授权判定：有效期、可谈范围校验 |
| `src/domain/sessions.ts` | 会谈流转：入档分类、紧急提交、补签、关闭、版本链 |
| `src/domain/audit.ts` | 变更记录 |
| `src/store/localStore.ts` | 本地保存（localStorage，四个集合分别存取） |
| `src/data/seed.ts` | 演示数据（含授权过期仍保存的缺陷场景） |
| `src/App.tsx` | 界面与交互 |
