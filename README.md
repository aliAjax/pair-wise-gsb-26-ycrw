# hxwl-12 未成年人咨询 · 授权与保密台账

在原「心理咨询个案记录」原型上扩展：监护人授权管理、会谈记录归档分流、督导紧急处置与变更台账。

## 核心规则

- 每个未成年个案保留 **监护人、可谈范围（含边界说明）、有效期限**；授权按版本保存，补签/变更新增版本，旧版本标记为「已被替代」但保留。
- 会谈记录保存时实时判定：**会谈日期在授权有效期内 + 主题全部落在可谈范围内** → 进入正式档案；否则一律先存 **受限草稿**（授权过期、主题超范围、个案关闭均不落正式档）。
- 紧急情况：仅 **督导** 可把受限草稿临时提交，必须写清紧急原因（≥4 字）与回访期限（不得早于当天），记录以「督导临时提交」入档并跟踪回访，超期有醒目标记。
- 监护人补签后，系统按新授权重新判定受限草稿，符合条件的自动复核转正；每次状态变化都追加 **版本链** 节点（草稿 → 正式/紧急 → 封存全程可溯）。
- 个案关闭：已入档/紧急提交记录封存为「关闭封存」，受限草稿与全部版本链保留备查。
- 所有写操作进入只追加的 **变更记录台账**（操作人、角色、个案、关联单据、原因）。

## 模块分离

| 目录 | 职责 |
| --- | --- |
| `src/modules/consent.ts` | 授权范围/有效期判定（纯函数，无 React、无存储依赖） |
| `src/modules/sessions.ts` | 会谈归档分流、版本链（纯函数） |
| `src/modules/audit.ts` | 变更台账文案与条目构造（纯函数） |
| `src/storage/` | 本地保存：通用 Repository + 四个独立 localStorage 仓库（cases / consents / notes / audit） |
| `src/LedgerContext.tsx` | 状态编排层，UI 不直接接触 localStorage |

## 技术栈

React 19 + Vite + TypeScript（strict）+ CSS

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5112
npm run build
```

界面右上角可切换 咨询师 / 督导 / 机构管理员 身份（紧急临时提交仅督导可用）。演示基准日固定为 2026-09-25，覆盖三种情形：

- **M-042**：授权有效（至 2026-12-31），会谈正常入档
- **M-117**：授权 2026-08-31 过期，9 月会谈存受限草稿，补签后可转正
- **M-203**：主题「家庭冲突」超范围存草稿；另有一条督导紧急提交（回访期限 9-24，演示超期）

页面底部「本地保存」面板可查看四个独立仓库的 key / 条数 / 字节数，并可一键重置演示数据。
